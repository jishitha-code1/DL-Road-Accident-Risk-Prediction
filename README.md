# DL-Based Road Accident Risk Prediction

## Project Description

This project uses Deep Learning to predict road accident risk based on factors such as weather, traffic level, road condition, visibility, and time of day.

The system takes user-provided road and environmental conditions and predicts the corresponding accident risk category.

Explainable AI using SHAP is used to understand which input factors influenced the prediction.

## Objectives

- Collect and preprocess accident-related data
- Analyze important road and environmental factors
- Develop a Deep Learning model
- Predict accident risk
- Evaluate model performance
- Use SHAP for model explainability
- Develop a simple prediction prototype
